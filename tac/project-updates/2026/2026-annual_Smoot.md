# Smoot – 2025 Annual Review


## Project Health


Smoot demonstrated strong development momentum throughout 2025. The following milestones and outcomes were achieved during the year.


---


## Phase 1: Migration Completed


The Wanchain implementation was successfully migrated to the LFDT repository.  
The codebase was redesigned to be vendor-agnostic, improving flexibility and long-term sustainability.  
A modular architecture was introduced, allowing contributors to add and extend components independently.  
The project was established as a fully open-source codebase, intentionally designed to support and encourage community contributions.


---


## Phase 2: Project Smoot and Harmonia Lab Integration


Phase two focused on expanding Smoot’s capabilities through integration with complementary projects.  
The Smoot codebase was successfully merged with Harmonia (completed).


Harmonia is an open-source Hyperledger Labs project focused on identifying the constraints, requirements, and architectural principles needed to enable interoperability between blockchain networks in regulated financial environments.  
Harmonia was collaboratively initiated by contributors from R3 and Adhara.


In addition, research is currently underway to integrate Cacti connectors, further strengthening cross-network interoperability.


---


## Phase 3: Cross-Chain Application Development


An EIP-3643 cross-chain use case implementation has been completed.  
Enterprise-grade solutions are being developed on top of the Smoot framework.  
End-to-end use cases—including GUI components—have been delivered, and an EIP-3643 demonstration is ready.  
Developers can easily leverage the Smoot source code to build and extend cross-chain applications.  
Infrastructure providers can now enable third-party application development using Smoot-based components.


---


## Maintainer Diversity


The Smoot project currently has three active maintainers. Organizational diversity among maintainers remains an area for improvement:


- Wanchain: 2 maintainers, supported by a broader group of contributing developers  
- Adhara: 1 maintainer  


The Smoot project actively welcomes additional third-party organizations to participate as maintainers.


---


## Project Adoption


Smoot is a relatively new project, and production-level adoption is still limited. Outreach and ecosystem engagement remain key focus areas.


---


## Goals


### Performance Against Prior Goals


Smoot successfully achieved the goals set for 2025. In addition to the technical milestones described above, the following dissemination and community engagement activities were completed:


- Publication of a blog post introducing the Smoot project  
- Two community meetup presentations  
- Blog post announcing the merger of Smoot and Harmonia  
- Joint interoperability presentation with the Cacti project  
- Joint presentation at the LFDT Summit
